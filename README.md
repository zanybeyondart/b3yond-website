# B3YOND Website

Premium one-page studio site built with Astro 6 and Tailwind CSS 4.

## Commands

- `npm run dev` — local development
- `npm run check` — Astro, ESLint, and Prettier checks
- `npm run build` — production build to `dist/`

## Editing

- Project and capability content: `src/data/site.ts`
- Main page copy: `src/pages/index.astro`
- Visual system: `src/styles/global.css`
- Project placeholders: `public/projects/`

Replace the placeholder project titles/images with approved B3YOND work before launch. Update the canonical `site` URL in `astro.config.ts` after selecting the final domain.
